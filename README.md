# Learning Hub Backend

Learning Hub Backend is a REST API built with Node.js, Express, and MongoDB.

## Features

- JWT Authentication
- User Registration
- Role-based Authorization
- Learning Modules
- Notes Management
- DOCX to Markdown Conversion
- AI Features (Coming Soon)

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
- express-validator

## Project Structure

src/
├── config/
├── controllers/
├── middleware/
├── models/
├── repositories/
├── routes/
├── services/
├── utils/
└── validators/

npm install
